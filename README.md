# Multi Angol

## Propuesta de Valor
Somos **Multi Angol** que ayudamos a **pequeñas empresas, talleres y hogares de la zona** mediante **el desarrollo de soluciones tecnológicas a la medida y soporte técnico especializado en reparación de equipos y sistemas**.

## Servicios que Ofrecemos
1. **Soporte y Reparación Tecnológica:** Diagnóstico y mantención avanzada de equipos, hardware y componentes electrónicos.
2. **Desarrollo de Software y Aplicaciones:** Creación de plataformas web y móviles funcionales para optimizar procesos locales.
3. **Consultoría y Automatización:** Implementación de sistemas de control, bases de datos y herramientas de seguridad operativa.
